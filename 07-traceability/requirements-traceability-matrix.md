## Notes

- Test cases are proposed and have not been executed against a real system.
- Traceability links should be reviewed against the full requirements and test documentation.
- Requirements, user stories and test cases may be revised as the project develops.
- This is a conceptual portfolio project and is not an official Wits system proposal.
